# Phoenix Vows

*Wedding brand and editorial specs, in paper and ink.* A warm, magazine-style system for wedding businesses: how their words, layouts and photographs should feel.

Part of Phoenix Mobile Advertising. We serve small businesses in **Eugene, Springfield, Salem, Portland and Roseburg, Oregon**, with the same class of tools the big platforms use, set up for local businesses. We are not affiliated with Google, Meta or OpenAI.

## What is here

- [specs/editorial.md](specs/editorial.md): tone, layout grid, photography direction, palette, type and example headline structures

## The feel

Quiet, warm and personal, like a good printed invitation. Lots of paper, ink-dark type, one soft accent. Honest words, real photographs, no hype.

## Principles

- **Provable.** Claims point to something you can open.
- **Clickable.** Every link is tested.
- **No fakes.** No invented couples, reviews, prices or vendors. Examples are labeled as examples.
- **AI education.** Owners learn what the tools do and keep control of the story.
- **A person approves** every piece before it goes out.

## Palette snapshot

Paper `#f4efe6`, ink `#12100e`, a muted ember `#e36a2e` used sparingly. See the spec for the full set.
