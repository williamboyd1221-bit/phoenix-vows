# Demo unit template: Phoenix Vows

**Standard:** one repo per service, one folder per demo, one dated entry per run. Commit history shows it was built, not borrowed.
**Folder name:** `demos/YYYY-MM-DD-short-name/` (date in Pacific time, PT).

Copy this file into the new demo folder as `DEMO_UNIT.md` and fill every row. Leave a slot as **pending** until the real media exists. Never add placeholder, mocked or borrowed media.

| Slot | Status (`pending` or `done`) | Link or file | Timestamp (PT) |
|---|---|---|---|
| 1. Before video (how it works today, no Phoenix workflow) | pending | | |
| 2. Workflow running (screen recording or live log of the workflow doing the work) | pending | | |
| 3. After video (the result, in the owner's real setting) | pending | | |
| 4. Timestamp (date and time of the run, PT) | pending | | |
| 5. Link (public URL or this repo path for the proof) | pending | | |

## Also record in each demo folder
- `README.md`: what the demo shows, the date, the person who approved it, the result.
- `METHOD.md`: exact steps and tools, so anyone can repeat it.
- Source links for every claim.
- Public-safe only: no client names without written permission, no credentials, no private links, no personal or financial records.
